КАК ПОЛУЧИТЬ ПЛАГИН (без установки программ):

1. Зайди на github.com и зарегистрируйся (бесплатно).
2. Нажми "+" вверху справа -> New repository -> назови как хочешь -> Create repository.
3. Нажми "uploading an existing file", распакуй этот архив и перетащи ВСЁ
   содержимое папки (вместе с папкой .github) в окно. Нажми Commit changes.
4. Открой вкладку Actions. Сборка запустится сама (около 5-10 минут).
   Когда появится зелёная галочка - открой её и внизу скачай Shtrashilkin-Tuner-VST3.
5. Распакуй скачанное. Папку "Shtrashilkin Tuner.vst3" скопируй в
   C:\Program Files\Common Files\VST3
6. FL Studio 25: Options -> Manage plugins -> Find installed plugins.
